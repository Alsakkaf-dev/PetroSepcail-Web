Source: the Lucide project (lucide.dev, source at github.com/lucide-icons/lucide),
`icons/*.svg`. Vendored, not installed. No runtime dependency, no CDN — per the standing
vendor constraint in DEFERRED-DECISIONS Section 3. Each glyph in glyphs.tsx
carries its upstream Lucide icon name in a comment so a future upgrade is a
mechanical diff against that file.

Changes made to the upstream artwork:
  * The `xmlns`, `width`, `height`, `stroke-width`, `stroke-linecap` and
    `stroke-linejoin` attributes are dropped from each glyph — the shared
    <Icon> wrapper supplies them once, and an xmlns URI would fail
    parity-grep. Only the geometry elements are vendored.
  * stroke-width is set to 1.8 (Lucide ships 2) to match the hand-written
    inline SVGs already in assets/ and index.html, so the marketing site and
    the applications read as one company.
